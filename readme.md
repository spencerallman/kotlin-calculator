# Kotlin Calculator

In this project, I designed a basic calculator program that runs on the command line. It asks for user input and can perform basic math operations such as addition, subtraction, multiplication, and division. The program also keeps track of the calculations you perform, and gives you the ability to see your calculation history as well as clear it.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Set up Kotlin functionality on your device
2. Download or copy and paste the Main.kt and Calculator.kt files
3. Run the Main.kt file

Instructions for using the software:

1. Using the command line, follow the instructions of the menu by inputting a number
2. Input the number 1 to start a new calculation and follow the instructions as it asks you to input numbers and operators
3. When finished, input the number 4 to end the program

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* IntelliJ or other IDE capable of running Kotlin files
* JDK or OpenJDK
* Kotlin extension for language support
